# Saket745 Live GitHub Dashboard

This is the **dynamic** version of the profile dashboard. It is a real web application, not a generated README image.

## Data flow

```text
GitHub repositories
   │
   ├─ push / commit
   ├─ pull_request
   ├─ issues
   ├─ repository
   ├─ star / fork
   └─ review activity
            │
            ▼
     GitHub App webhook
            │
            ▼
       POST /webhooks/github
            │
            ├─ verify HMAC signature
            ├─ record live event
            └─ refresh authoritative GitHub data
                        │
                        ▼
                  /api/stats
                        │
                        ▼
                 WebSocket /ws
                        │
                        ▼
                glass dashboard UI
```

GitHub Apps can receive real-time webhook notifications for events such as pushes and pull requests. A GitHub App installation token is short-lived and should be generated by the server when needed.

## 1. Create a GitHub App

Create a **private GitHub App** under your GitHub account.

Enable the App webhook and use the final public URL of this server:

```text
https://YOUR-DOMAIN.example/webhooks/github
```

Set a long random webhook secret.

Recommended repository permissions for this read-only dashboard:

- Metadata: Read-only
- Contents: Read-only
- Issues: Read-only
- Pull requests: Read-only

Subscribe to these events:

- Push
- Pull request
- Issues
- Issue comment
- Repository
- Star
- Fork
- Release
- Pull request review
- Pull request review comment

Install the App on your `Saket745` account and select **All repositories** so future repositories are covered by the installation.

## 2. Configure the server

Copy `.env.example` to `.env` and fill in:

```text
PORT=3000
GITHUB_USERNAME=Saket745
GITHUB_APP_ID=...
GITHUB_INSTALLATION_ID=...
GITHUB_WEBHOOK_SECRET=...
GITHUB_PRIVATE_KEY=-----BEGIN PRIVATE KEY-----\\n...\\n-----END PRIVATE KEY-----\\n
```

Never commit `.env` or your App private key.

## 3. Run locally

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000
```

For local webhook development you need a public HTTPS tunnel, or deploy the server first.

## 4. Deploy

This folder is container-ready. Deploy it on any service that supports a long-running Node.js process or Docker container.

Use `Dockerfile` and expose port `3000`.

Set the environment variables from `.env.example` in the hosting provider's secret/environment settings.

## Why this is different from the previous widget system

The old system generated SVG files and committed them back to GitHub. The new system keeps the dashboard as an application:

- the browser renders the glass UI with HTML/CSS/JavaScript
- GitHub events arrive through webhooks
- the server refreshes the underlying statistics
- connected browsers receive the new state through WebSockets
- the dashboard redraws immediately without replacing an image

There is no Git commit required for a normal stats change.
